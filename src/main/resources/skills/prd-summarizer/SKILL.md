# 需求文档摘要技能

## 能力
当你需要摘要 PRD / 需求文档时，使用此技能。

## 输入
- 文档：PRD.md 或需求说明文件
- 摘要类型：简要 / 详细

## 流程
1. 通读文档章节结构（背景、目标、功能需求、非功能需求、里程碑）
2. 提取核心信息：
   - 产品目标与目标用户
   - 功能需求清单（编号、优先级）
   - 非功能约束（性能、安全、隔离）
   - 里程碑与验收口径
3. 组织摘要结构：
   - 一句话产品定位
   - 核心能力列表（按 P0/P1 分组）
   - 关键约束
   - 里程碑进度

## 输出
结构化的 Markdown 摘要。
