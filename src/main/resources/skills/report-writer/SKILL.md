# 报告撰写技能

## 能力
当你需要生成数据分析报告时，使用此技能。

## 输入
- 数据：CSV 文件、JSON 数据或数据库查询结果
- 报告类型：摘要 / 详细分析 / 对比报告

## 流程
1. 理解数据结构和字段含义
2. 分析关键指标和趋势
3. 使用图表（如果可用）可视化数据
4. 组织报告结构：
   - 执行摘要
   - 数据概览
   - 关键发现
   - 详细分析
   - 结论与建议
5. 输出格式：Markdown 文件

## 输出
结构化的 Markdown 报告文件。
