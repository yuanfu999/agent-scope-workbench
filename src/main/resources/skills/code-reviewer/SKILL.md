# 代码审查技能

## 能力
当你需要审查代码质量时，使用此技能。

## 输入
- 语言：Java / Python / JavaScript / TypeScript / Go 等
- 范围：文件列表或 Git diff

## 流程
1. 先理解代码的整体结构和功能
2. 逐文件检查：
   - 命名规范（UpperCamelCase / lowerCamelCase / 常量全大写）
   - 代码格式（缩进、空格、空行）
   - 潜在的 bug（空指针、资源未关闭、并发问题）
   - 安全漏洞（SQL 注入、XSS、敏感信息泄露）
   - 性能问题（不必要的循环、未优化的查询）
   - 测试覆盖（缺少单元测试、边界情况）
3. 对于每个问题，给出：
   - 文件路径和行号
   - 问题描述
   - 修复建议
4. 总体评分（1-5）

## 输出
审查报告，包含问题列表和改进建议。
